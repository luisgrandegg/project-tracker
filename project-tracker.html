First-time setup

Connect to Supabase

This tracker syncs through a Supabase project so multiple people can share the same items in real time. Paste your Project URL and the publishable / anon key below to get started.

01

Have a Supabase project ready

If you don't already have one, sign up at supabase.com (free tier is plenty) and create a new project.

02

Run the setup SQL once

In your Supabase dashboard go to SQL Editor → New query, paste this in, and run it. It creates the table, sets access rules, and enables real-time updates.

create table public.tracker_items ( id uuid primary key default gen_random_uuid(), title text not null, description text default '', status text not null, owner text not null, due_date date, start_date date, completed_at timestamptz, created_at timestamptz default now(), updated_at timestamptz default now(), log jsonb default '[]'::jsonb, labels text[] default '{}', attachments jsonb default '[]'::jsonb ); alter table public.tracker_items enable row level security; create policy "allow_anon_all" on public.tracker_items for all to anon, authenticated using (true) with check (true); alter publication supabase_realtime add table public.tracker_items; -- If you already created the table before some of these columns existed, -- run these alters to bring an older table up to date (safe to re-run): -- alter table public.tracker_items add column if not exists start_date date; -- alter table public.tracker_items add column if not exists attachments jsonb default '[]'::jsonb; -- alter table public.tracker_items add column if not exists labels text[] default '{}';
03

Paste your project credentials

In Supabase go to Project Settings → API and copy your Project URL and the anon / publishable key (not the service_role key).

Stored in your browser only
For someone joining you later: they'll open this same page, paste the same Project URL and key, and click Configure — then they'll see the same tracker, with changes syncing in real time.
